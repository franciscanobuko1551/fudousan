## 1. 利用規約の叩き台

### 1.1 サービスの目的

Kokoro Navi AI は、ユーザーが自分の気持ちや状況を言葉にし、やさしく整理し、今日できる小さな一歩を見つけるためのAI相談サービスです。

### 1.2 サービスの限界

本サービスは、医療、心理療法、法律、金融、緊急対応、その他専門資格を必要とする助言を提供するものではありません。回答は一般的な整理や気づきの補助であり、診断、治療、法的判断、投資判断、緊急時の判断を代替しません。

### 1.3 緊急時の利用

自分や他人を傷つけるおそれがある場合、虐待、DV、脅迫、重大な危険がある場合は、本サービスではなく、身近な人、地域の相談窓口、医療機関、警察・消防などの緊急窓口へ連絡してください。

### 1.4 禁止事項

ユーザーは、次の目的で本サービスを利用してはいけません。

- 自傷・他害・虐待・DV・犯罪行為を促進すること。
- 他人の個人情報や機密情報を本人の同意なく入力すること。
- 医療、法律、金融などの専門判断をAIだけで確定すること。
- 本サービスや外部AIサービスの安全機能を回避しようとすること。
- 迷惑行為、嫌がらせ、差別、脅迫、違法行為に利用すること。

### 1.5 回答の正確性

本サービスの回答には、誤り、不完全な情報、ユーザーの状況に合わない提案が含まれる場合があります。重要な判断を行う場合は、必要に応じて専門家または信頼できる人に相談してください。

### 1.6 サービスの変更・停止

本サービスはプロトタイプ段階です。機能、画面、保存方式、利用条件は予告なく変更または停止される場合があります。

### 1.7 免責

本サービスの利用により生じた損害について、運営者は、法令上認められる範囲で責任を負いません。ただし、運営者に故意または重大な過失がある場合はこの限りではありません。

## 2. プライバシーポリシーの叩き台

### 2.1 取得する情報

現時点のプロトタイプでは、次の情報を扱います。

- ユーザーが入力した相談ジャンル。
- ユーザーが入力した相談内容。
- AIまたはフォールバックで生成された回答。
- 相談日時。
- ブラウザ内に保存される相談履歴。

現時点では、ユーザー登録、氏名、メールアドレス、住所、電話番号などを入力する機能はありません。

### 2.2 利用目的

取得した情報は、次の目的で利用します。

- 相談内容に対する回答を生成するため。
- ブラウザ内で最近の相談履歴を表示するため。
- サービスの安全性、品質、動作確認を行うため。
- 不具合や不正利用の調査を行うため。

### 2.3 保存場所

相談履歴は、ユーザーが利用しているブラウザの `localStorage` に保存されます。現時点では、Kokoro Navi AI のサーバーや外部DBに相談履歴を保存しません。

ただし、`OPENAI_API_KEY` を設定して利用する場合、相談ジャンル、相談内容、深掘り方向は OpenAI API に送信されます。

### 2.4 OpenAI APIへの送信

OpenAI API を利用する場合、入力内容と応答生成に必要な情報が OpenAI に送信されます。OpenAI の公式ドキュメントでは、APIに送信されたデータは、明示的に共有を選択しない限り、モデルの学習・改善には使用されないと説明されています。また、不正利用対策などのために、デフォルトで一定期間の監視ログが保持される場合があります。

### 2.5 要配慮情報について

相談内容には、病歴、心身の状態、家庭環境、犯罪被害、信条など、慎重に扱うべき情報が含まれる可能性があります。ユーザーは、必要以上に詳しい個人情報や第三者の個人情報を入力しないでください。

運営側でサーバー保存を導入する場合は、取得する情報、利用目的、保存期間、削除方法、外部送信先を事前に明示し、必要な同意の取り方を設計します。

### 2.6 履歴の削除

ブラウザ内に保存された相談履歴は、画面上の「履歴を削除」ボタンで削除できます。共有端末を利用する場合は、相談後に履歴を削除してください。

### 2.7 履歴保存の選択

ユーザーは、相談送信前に「この相談をこのブラウザの履歴に保存する」のチェックを外すことで、その相談をブラウザ履歴に保存しない選択ができます。

### 2.8 外部提供・委託

現時点では、OpenAI APIへの送信を除き、相談内容を外部事業者に提供しません。将来、分析、監視、データ保存、問い合わせ対応などで外部サービスを利用する場合は、この文書に追記します。

### 2.9 問い合わせ窓口

正式公開前に、運営主体名、問い合わせ先、受付方法を記載します。

## 4. Phase 1で確定する項目

- 運営主体名。
- 問い合わせ先。
- 対象年齢と未成年利用の扱い。
- 相談履歴をサーバー保存するかどうか。
- 保存する場合の保存期間、削除方法、本人確認方法。
- OpenAI以外の外部サービス利用有無。
- 緊急窓口案内の地域・言語対応。
- 利用規約とプライバシーポリシーへの同意導線。
- 画面上の「利用上の注意を確認しました」チェックを、正式な規約同意として扱うか、プロトタイプ用の確認導線として扱うか。
- 画面上の利用規約、プライバシーポリシー、免責文言リンクは追加済み。正式な同意範囲、問い合わせ先、運営主体は未確定。
